# AWS VPC Cloud Networking: Multi‑Part Architecture Build

This project walks through the design and deployment of a full AWS Virtual Private Cloud (VPC) networking environment across nine structured stages.
It covers subnet design, routing, NAT configuration, VPC peering, VPC endpoints, and core security controls.
Each stage includes a workflow diagram to visualize traffic flow and architecture behavior.

---

## Project Overview

This project demonstrates how to:

- Build a custom VPC with defined CIDR ranges
- Create public and private subnets across multiple AZs
- Configure route tables, Internet Gateways, and NAT Gateways
- Implement VPC peering and VPC endpoints
- Apply Security Groups and Network ACLs for layered security
- Use IAM roles and S3 bucket policies for least‑privilege access
- Enable and analyze VPC Flow Logs for traffic visibility
- Test connectivity using EC2 instances, AWS CLI, and CloudWatch logs
